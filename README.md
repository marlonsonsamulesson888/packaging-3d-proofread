# 包装 3D 图文防错

帮助对照已确认平面稿，检查包装效果图中文字、Logo、图案的方向、位置、完整性与多角度版本一致性。

## 能做什么
- 提供逐面、逐视角的检查方法。
- 用本地 Python 脚本准备检查记录，校验文件版本、证据和未检查项。
- 可选读取使用者自己的历史错误 JSON，不附带任何真实订单资料。

## 不能做什么
脚本不会看图、识别文字、修图或自动判定设计正确。记录完整也不等于视觉合格，更不代表印刷生产批准。需要能看图的助手或人员实际检查。

## 使用
将这个文件夹作为技能安装到您所用 Codex 支持的技能目录，并在新会话确认能发现 `packaging-3d-proofread`。不同版本安装入口可能不同，请参照当前官方说明：https://learn.chatgpt.com/docs/build-skills 。本仓库不需要其他自定义技能。

直接阅读 SKILL.md 也可按步骤人工检查。辅助脚本需要 Python 3.10+，无需第三方依赖。

在本目录运行：

```sh
python scripts/review.py prepare --spec examples/job.json --out review-output-demo
python scripts/review.py check --review review-output-demo/review.json
python -m unittest discover -s tests -v
```

示例是自己绘制的简化 SVG，用于演示记录结构，不是真实客户包装或真实三维渲染。初始检查结果应为未验证，check 返回 2 是预期结果。查看实际图像后如实填写，禁止为得到通过结果而编造证据。输出目录必须是新目录。

## 隐私
本工具仅操作本地文件，不调用网络或上传。生成的记录会包含本地路径及您指定的历史条目，请保持私有，不要提交到本仓库。

## 验证范围
提供合成单元测试，覆盖未验证项、版本变化、缺失证据和不覆盖源文件等行为。这些测试不能替代真实订单、原生 AI 文件重开或印前验收。
